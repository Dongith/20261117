A deterministic Python program that draws a newspaper-style front page summing up Tuesday 17 November 2026 world news. The lead story covers the US strikes on Iran after the Hormuz tanker attacks, with six more stories — Ukraine, Trump in Asia, US measles, Japan, Gaza and Wall Street — laid out in a two-column grid. It renders a clean 1024x1024 PNG on warm off-white paper using only the Python standard library and Pillow, with no network access and byte-identical output on every run.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024).
